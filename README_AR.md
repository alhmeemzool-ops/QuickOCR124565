# Quick OCR

تطبيق أندرويد ينفذ الاختصار التالي:

**هز الجهاز → فتح الكاميرا فوق التطبيق الحالي → التقاط صورة تلقائياً → OCR للأرقام فقط → لصق الرقم في الخانة المحددة.**

## تشغيل التطبيق
1. افتح خدمة `Quick OCR` من إعدادات إمكانية الوصول وفعّلها.
2. امنح التطبيق إذن الكاميرا.
3. هز الجهاز هزّة قوية واحدة.
4. ستفتح الكاميرا فوق التطبيق، تُلتقط الصورة، ثم يحاول التطبيق لصق الرقم في الخانة المركّز عليها. إذا لم تكن الخانة قابلة للكتابة، يُنسخ الرقم إلى الحافظة.

## بناء APK من GitHub
المشروع يحتوي على GitHub Actions. عند رفعه إلى GitHub على فرع `main` أو `master` سيقوم GitHub بتنزيل نماذج Tesseract العربية والإنجليزية ثم بناء APK وإرفاقه كـ Artifact باسم `QuickOCR-debug`.

نماذج OCR مأخوذة من مستودع Tesseract الرسمي `tessdata_fast`.
